# Ключевые изменения по сравнению с изначальным вариантом

- **Единые HTTP-настройки.** Добавлены общие заголовки NetBackup API и сессия `requests` с ретраями, чтобы повторять неудачные запросы и уменьшить количество ручного кода обработки ошибок.
- **Надёжная пагинация.** Введена вспомогательная функция `fetch_all_pages`, которая проходит по всем страницам ответов с учётом ссылок `next`, нормализует относительные URL через `urljoin` и не ходит по уже посещённым ссылкам.
- **Сбор заданий через все страницы.** Метрики `nbu_jobs_status` и `nbu_24h_jobs_status` теперь наполняются после обхода полного списка заданий, а фильтр последних 24 часов применяется к каждой записи уже после пагинации.
- **Оптимизирован сбор хранилищ.** Список storage units загружается постранично один раз; в одном цикле обновляются метрики использованной, свободной и общей ёмкости для каждого хранилища.
